# Python E-Commerce Shopping Cart

A simple E-Commerce Shopping Cart System built using Python and Object-Oriented Programming (OOP).

## Features

- Product management
- Shopping cart management
- Add and remove products
- Product price calculation
- Order management
- UPI, Card and Cash payment

## OOP Concepts Used

- Classes and Objects
- Constructor
- Encapsulation
- Getter and Setter
- Inheritance
- Method Overriding
- Polymorphism
- Abstraction
- Composition

## Technology

- Python
